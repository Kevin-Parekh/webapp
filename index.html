Which tool should I use?

Recommended for beginners: AI chat + VS Code

ChatGPT, Claude or Gemini in the browser, and VS Code + Live Server on your laptop. Paste one prompt, save the files yourself, test. Slower, but you see and understand every file. This guide is written for this method.

Faster: AI code editors

Cursor, Google Antigravity, VS Code Copilot (Agent mode) or OpenAI Codex. Open the project folder, paste the same prompts into the editor's AI chat, and review and accept the changes. The AI creates and edits files for you, so there are fewer copy-paste mistakes. Great for the second project.

Golden rule: do all 25 steps in one single chat, so the AI remembers your PRD and code. If the AI stops in the middle of a long answer, type continue. If something breaks, open the Debugging tab.
How to save code in VS Code: New file: click the "New File" icon in the Explorer, type the exact name (for example css/style.css creates the folder too), paste, save. "Replace all code": click in the file, Ctrl+A, then paste. "Add at the end": click in the file, Ctrl+End, press Enter, then paste.

Troubleshooting with AI

Errors are normal. Even professional developers see them every day. The skill is to give the AI exact information so it can find the cause. A vague message like "it's not working" gets a vague answer. Follow this loop every time:

1See the error
2Capture it: screenshot + copy the text
3Find the file and the step
4Fill an error prompt and send
5Apply the fix exactly
6Test again. Repeat if needed
Where do errors appear? Website errors: in the browser's Console (F12 > Console) or visible on the page. Python errors: in the terminal where you ran python app.py, and sometimes in the browser as "Internal Server Error".

How to read a Python traceback (in 3 steps)

  1. Read the last line first. It has the error type and message, for example NameError: name 'render_template' is not defined.
  2. Find the last "File ..." line that is YOUR file (app.py, database.py). Ignore lines with site-packages or flask folders; that is library code.
  3. Open that file at that line number. In VS Code press Ctrl+G and type the line number.

Golden rules of debugging with AI

  1. One error at a time. Fix the first red error first; it often causes the others.
